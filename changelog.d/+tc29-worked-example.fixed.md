**TC-29 no longer fails an explanation for its worked example.** "It squares each number in
range(5), giving [0, 1, 4, 9, 16]. For example, [1, 2, 3] becomes [1, 4, 9]." failed as stating a
wrong result list. A list pair on other input now counts as an example when an example marker
("for example", "e.g.", "such as", "if") opens its sentence and the second list squares the first.
A cubed example, a wrong stated result, and an unmarked pair such as "squares [1, 2, 3, 4, 5],
giving [1, 4, 9, 16, 25]" still fail. TC-29 scores can rise for answers that illustrate the
comprehension.
