Four bugs in the newly added CI jobs, caught by their first run: `pre-commit run` takes one hook id rather than a list, `pip-audit --strict` failed on the project's own unpublished editable install, the `uv run` rewrite leaked into a job that installs with pip, and mypy ran on Windows where `termios` and `tty` do not exist. Lint, format, and mypy now run on Linux only; the extra runners exist to exercise runtime behaviour.
