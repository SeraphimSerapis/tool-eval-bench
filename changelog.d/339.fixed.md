**Structured-output prompts in TC-65, TC-66, TC-67, and TC-69.** These four scenarios now instruct the model to reply with only valid JSON matching the schema, with no extra text and no further tool calls, once it has the tool data. Previously, whether a model received that rule on turn 2 depended on the inference server injecting it alongside `response_format`. The German, Spanish, Chinese, and Japanese packs carry the matching TC-67 update, and `LOCALE_VERSION` moves to 2.
