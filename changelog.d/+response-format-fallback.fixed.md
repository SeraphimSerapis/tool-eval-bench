**Structured-output scenarios now grade the model when the endpoint rejects `json_schema`.** Some providers, DeepSeek among them, accept `response_format: {"type": "json_object"}` but answer `json_schema` with HTTP 400. TC-64 failed as a server error, and TC-65/66/67/69 were scored PARTIAL as "not valid JSON" because the rejection came after the tool call. A 400 or 422 on a turn that carried `response_format` now retries the turn with `json_object`, then with no `response_format`. Every structured prompt already embeds the schema, so the model is still graded against it. The fallback is recorded in the trace (`response_format_fallback=`) and in the scenario's `response_format` diagnostic. The rejection that triggers the fallback is logged at debug level instead of printing a warning.
