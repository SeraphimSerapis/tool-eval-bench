**A scenario filter that matches nothing is a usage error instead of an empty run.** `--categories P` without `--hardmode`, `--short --categories K`, and `--hardmode-only --categories A` used to complete a 0-scenario run, store it with a score of 0 and a "★ Poor" rating, and list it in `history` and `leaderboard`. They now exit 2 before model discovery, with an `invalid_arguments` event under `--json`, and the message suggests `--hardmode` when Category P was requested. Modes that send no scenarios, such as `--perf-only` or a plugin-only run, ignore the selection as before, and `resume` is unaffected. `BenchmarkService.run_benchmark` raises `ValueError` for an empty scenario list outside a resume.
