The test suite runs on Windows, and the CI matrix has a Windows runner again. Two of the failures it originally reported were product bugs, not test assumptions: context-pressure filler was seeded from `time.time_ns()`, which advances in ~15.6ms steps there, so two builds inside one tick produced byte-identical text and handed the server the warm prefix cache that noise exists to defeat; and scenario durations and simulated async-tool progress were measured with `time.monotonic()`, which has the same coarse tick, instead of `time.perf_counter()`.
