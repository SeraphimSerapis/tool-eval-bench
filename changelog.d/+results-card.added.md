`tool-eval-bench card` renders a benchmark session as one shareable SVG, with PNG export through the new `[card]` extra: decode and prefill speed, time to first token across context depths, concurrency scaling, needle retrieval, tool-calling quality, and GSM8K, MMLU, and IFEval accuracy. It picks the latest session by default, takes `SESSION`, `--model`, or repeatable `--run RUN_ID` for runs stored before sessions existed, and adds `--hardware`, `--layout portrait|landscape`, `-o`, `--png`, and `--scale`. The card never carries a hostname, server URL, session or run id, label, tokenizer path, or system prompt. Needle runs now store their retrieval grid as coordinates and outcomes, so the card can draw it. A `--trials` run is shown as the mean of its trials, a run with fewer scenarios than the suite is marked as a subset, and needle cells whose request errored show as not measured rather than as misses.
