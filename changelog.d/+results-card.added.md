`tool-eval-bench card` renders a benchmark session as one shareable SVG, with PNG export through the new `[card]` extra: decode and prefill speed, time to first token across context depths, concurrency scaling, needle retrieval, tool-calling quality, and GSM8K, MMLU, and IFEval accuracy. It picks the latest session by default, takes `SESSION`, `--model`, or repeatable `--run RUN_ID` for runs stored before sessions existed, and adds `--hardware`, `--layout portrait|landscape`, `-o`, `--png`, and `--scale` from 0.25 to 8. The card never carries a hostname, server URL, session or run id, label, tokenizer path, or system prompt, and a model served from a local path is named by its model directory rather than the path. The default file is `cards/<model>-<YYYYMMDD>-<fingerprint>.svg`; `-o` takes a file or a directory; another image or document suffix such as `.jpg` or `.pdf` exits 2, and any other name gets `.svg` appended, so `-o Qwen3.5-27B` keeps its dot. If the PNG cannot be written, the SVG is still saved and the command exits 1. Needle runs now store their retrieval grid as coordinates and outcomes, so the card can draw it. A `--trials` run is shown as the mean of its trials, a run with fewer scenarios than the suite is marked as a subset, accuracy is computed over the questions that got an answer with the errored count shown, a benchmark where every question errored reads as not measured, and needle cells whose request errored show as not measured rather than as misses. Combining runs from different tool or engine versions prints a warning.
