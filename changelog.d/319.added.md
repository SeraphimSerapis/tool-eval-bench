**Toolscale sweep with `--toolscale` / `plugin toolscale`.** A new plugin measures
tool-selection accuracy as the number of offered tools and the similarity of the target's nearest
neighbours vary independently, from a 1-tool control up to 64 tools. A 272-tool catalog of 17
domains, 4 families each, and 4 near-duplicate variants per family defines the near, related, and
distinct tiers, and a TF-IDF check confirms the ordering. The report gives accuracy per cell with
Wilson intervals and trial spread, paired similarity and count effects with bootstrap intervals, an
error mix that separates neighbour confusion from filler picks, accuracy among items where a tool
was called (so abstention is not read as confusion), accuracy by target position, and
where Category L's 52-tool set sits on the same similarity scale. `--toolscale-catalog PATH` runs a
private catalog whose items the report withholds. Category L scores are unchanged. See
`docs/toolscale.md`.
