**Context pressure prefills its filler once per run instead of once per scenario.** Each scenario used to tag its first filler message with `[scenario:TC-xx]`, so every scenario's prompt diverged right after the system prompt and the server prefilled the whole fill again: about 73 seconds per scenario for a 134K fill at 1,800 tokens/s, or two hours of prefill for a Hard Mode run. The tag was added for #4, when the first, cold scenario timed out while later ones ran from cache. Scenarios now share the filler, and one unscored warm-up request (`max_tokens=1`) prefills it before the first scenario, so every scenario starts from the server's prefix cache. A cached prefix gives the model the same KV as a cold one, so scores are unaffected. Scenarios with their own toolset still prefill cold, because chat templates usually render tools ahead of the messages.
