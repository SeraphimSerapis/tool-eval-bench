**TC-21 grades the issues it asks for instead of the wording around them.** The old grader matched diagnosis vocabulary with regular expressions, so three answers that named all five errors could score 4, 3, and 2 depending on phrasing ("outside the allowed range", "lacks a valid domain label", "only `5` digits"). It also credited a wrong reason as long as the field and value appeared together. TC-21 now numbers its rules R1 to R5 and asks the model to end with an `ISSUES:` section of `field: rule id` lines, which the grader reads exactly. A field counts only with the right rule, so a wrong reason earns nothing. The payload adds a valid decoy for every rule (age 150, a phone with parentheses, a leap day, zero, a subdomain email) and makes the invalid values sit on the rule edges (age 151, 2023-02-29), so flagging valid fields now costs points. PASS needs all five invalid fields and no false flags; PARTIAL needs right flags minus false flags of at least three. TC-21 results are not comparable with earlier runs.
