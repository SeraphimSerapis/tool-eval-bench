**TC-30 combined workflow order and two-call recovery.** TC-30 now accepts combined `run_code` programs that print `2 + 2` before assigning the result variable or use walrus assignment inside `print(result := 2 + 2)`, returning `4\ncorrect` instead of an `Unknown code` error. When an earlier `run_code` call fails or goes unrecognized and a later turn recovers with the full conditional workflow, TC-30 scores `PARTIAL` rather than `FAIL`, while ungrounded branch calls remain `FAIL`.
