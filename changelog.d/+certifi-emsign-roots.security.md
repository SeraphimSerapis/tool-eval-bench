**Locked `certifi` no longer trusts the compromised emSign root.** `uv.lock` pinned certifi 2026.7.22, whose CA bundle includes `emSign ECC Root CA - G3`. Eight eMudhra intermediates under that root have leaked private keys ([GHSA-6q48-6c7w-9gw2](https://github.com/advisories/GHSA-6q48-6c7w-9gw2)), so anyone holding one could impersonate the benchmark server or Hugging Face to the Docker image or a `uv sync` checkout. The lock now pins certifi 2026.10.23. A `pip install` resolves certifi on its own and is unaffected by the lock, so upgrade it there with `pip install -U certifi`.
